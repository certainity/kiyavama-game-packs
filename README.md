# Kiyavama Game Packs

Public runtime distribution for the Kiyavama app.

This repository contains compiled/versioned web-game packs, manifests, shared runtime assets, and a browser preview hub. Editable game source remains private in `certainity/kiyavama-games`.

The public catalog will be available at:

`https://certainity.github.io/kiyavama-game-packs/game-packs/catalog.json`

Preview hub:

`https://certainity.github.io/kiyavama-game-packs/preview/`
