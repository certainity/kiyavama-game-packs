# Kiyavama Game Packs

Public runtime distribution for the Kiyavama app.

This repository contains compiled/versioned web-game packs, manifests, shared runtime assets, and the browser preview hub. Editable game source remains private in `certainity/kiyavama-games`.

## Current distribution

- Published game packs: **83**
- Runtime branch: **`gh-pages`**
- Latest migrated runtime commit: **`55e923f717dbb0c95021b45a4323e2d824b1007e`**
- Source code is **not** stored in this public repository.

## GitHub Pages

Enable Pages once in **Settings → Pages**:

- Source: **Deploy from a branch**
- Branch: **`gh-pages`**
- Folder: **`/ (root)`**

After Pages is enabled:

- Catalog: `https://certainity.github.io/kiyavama-game-packs/game-packs/catalog.json`
- Preview hub: `https://certainity.github.io/kiyavama-game-packs/preview/`

The existing Wasabi copies can remain as rollback storage while Kiyavama transitions to the GitHub-hosted catalog.
